Práctica del Curso de JavaScript

Este proyecto contiene la replicación práctica de los conceptos explicados paso a paso en el curso para principiantes (sintaxis, variables, condicionales, bucles y funciones).

Instrucciones para la corrección:

Para visualizar las salidas y resultados de los ejercicios, haga clic derecho en cualquier parte de esta página, seleccione Inspeccionar y abra la pestaña Consola (o presione F12 / Ctrl + Shift + I).
